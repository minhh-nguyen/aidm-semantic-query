# Examples

Runnable examples and demos. Nothing here is shipped in the wheel.

- `how_to_use_api_proxy.py` currently lives in
  `src/aidm_semantic_query/how_to_use_api_proxy.py`. Move it here if you want
  to keep it out of the published package, then run it with:

```bash
uv run --env-file .env python examples/how_to_use_api_proxy.py
```
